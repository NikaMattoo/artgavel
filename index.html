როგორ მუშაობს

from studio wall to collector's wall

წესები და პირობები (შემოკლებული)

  • ლოტის განთავსებით გამყიდველი ადასტურებს ავტორობას ან გაყიდვის უფლებამოსილებას. საავტორო უფლებები რჩება ავტორს.
  • ბიდი სავალდებულო შეთავაზებაა — გამარჯვების შემთხვევაში მყიდველი ვალდებულია შეიძინოს ნამუშევარი.
  • ანტი-სნაიპინგი: დასრულებამდე ბოლო 2 წუთში დადებული ბიდი აუქციონს 2 წუთით ახანგრძლივებს.
  • გამყიდველს ეკრძალება საკუთარ ლოტზე ბიდის დადება პირდაპირ ან შუამავლით.
  • დასრულების შემდეგ მხარეები ჩატში თანხმდებიან გადახდასა და მიწოდებაზე. რეკომენდებულია დოკუმენტირებული გადახდა.
  • განთავსება უფასოა; წარმატებულ გაყიდვაზე შესაძლოა გავრცელდეს პლატფორმის მომსახურების საკომისიო, რომლის ოდენობა ცალკე ქვეყნდება.
  • წესების დარღვევა (ყალბი ავტორობა, ფიქტიური ბიდები) იწვევს ანგარიშის დაბლოკვას.

კონფიდენციალურობა

ვინახავთ მხოლოდ აუქციონისთვის საჭირო მონაცემებს: სახელი, ელფოსტა, ლოტები, ბიდები, კომენტარები, შეტყობინებები. მონაცემები არ იყიდება. ბიდერის სახელი საჯაროა — ეს გამჭვირვალობის ნაწილია. წაშლის მოთხოვნა: info@artgavel.ge

ხშირად დასმული კითხვები

რატომ მჭირდება ანგარიში ბიდისთვის?

ბიდი სავალდებულო შეთავაზებაა — ანგარიში იცავს გამყიდველს ფიქტიური ბიდებისგან და მყიდველს აძლევს ისტორიას, რეიტინგს და ბეჯებს.

როგორ ვიღებ ბეჯებს?

მხატვრები — დაგროვილი რეაქციებით და გაყიდვებით; კოლექციონერები — ბიდებითა და შესყიდვებით. ბეჯები შენს გვერდზე და ლიდერბორდზე ჩანს.

რა ხდება აუქციონის დასრულებისას?

ბოლო ბიდერი იმარჯვებს. მას და ავტორს ერთმანეთთან ჩატი ეხსნებათ გადახდისა და მიწოდების შესათანხმებლად.

ბოლო განახლება: ივლისი 2026 · info@artgavel.ge

პლატფორმის რეჟიმი

one paste from going live

როგორ ჩავრთო ლაივ რეჟიმი (Firebase)

  1. გახსენი console.firebase.google.com → Add project (სახელი: artgavel) → შექმენი.
  2. Build → Authentication → Get started → Sign-in method → ჩართე Email/Password.
  3. Build → Firestore Database → Create database → Start in production mode → ლოკაცია: eur3.
  4. Firestore → Rules → ჩასვი ქვემოთ მოცემული წესები → Publish.
  5. Project settings (⚙) → General → Your apps → Web app (</>) → Register → დააკოპირე firebaseConfig ობიექტი.
  6. ჩასვი ქვემოთ და დააჭირე „ჩართვა“.

Firestore Rules (დააკოპირე)

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read: if true;
      allow create: if request.auth != null && request.auth.uid == uid;
      allow update: if request.auth != null;
    }
    match /lots/{lot} {
      allow read: if true;
      allow create: if request.auth != null
        && request.resource.data.ownerUid == request.auth.uid;
      allow update: if request.auth != null;
      allow delete: if request.auth != null
        && resource.data.ownerUid == request.auth.uid
        && resource.data.bidCount == 0;
      match /{sub=**} {
        allow read: if true;
        allow write: if request.auth != null;
      }
    }
    match /chats/{chat} {
      allow read, write: if request.auth != null
        && request.auth.uid in resource.data.users;
      allow create: if request.auth != null
        && request.auth.uid in request.resource.data.users;
      match /messages/{msg} {
        allow read, create: if request.auth != null;
      }
    }
  }
}
